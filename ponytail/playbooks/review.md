# Review

Apply before declaring a coding task complete. Review the artifact, not the summary.

1. Read the full diff and relevant callers, types, tests, and boundaries.
2. Check the stated requirement and scope.
3. Look for deletion, reuse, native behavior, and simpler structure.
4. Check correctness, errors, config, security, ownership, and compatibility.
5. Confirm tests or executable evidence exercise the changed behavior.
6. Check boundary logging, PII, secrets, dead code, and debug output.
7. If authorized, fix blockers, rerun checks, and reread the diff. Otherwise report them.

Classify findings as blocker, concern, or nit. Do not manufacture findings. Report result, validation, fixes, and remaining risk.
