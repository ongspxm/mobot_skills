# Investigate

Use for code walkthroughs, behavior tracing, and ownership questions. Default to read-only.

1. State the best-guess question and scope.
2. Read applicable `AGENTS.md` files and project instructions.
3. Find entry points, symbols, types, callers, tests, config, and existing patterns.
4. Follow one real path from trigger to output or side effect.
5. Run the cheapest useful check when behavior is uncertain.
6. Check history only for surprising constraints.
7. Stop when the path is clear. Do not inventory unrelated code.

Return the overview, flow, relevant files, gotchas, assumptions, and smallest next step. Say "no change needed" when appropriate.
