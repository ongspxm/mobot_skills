# Arena

Use only when meaningful alternatives could lock in the wrong design. Skip tiny or obvious edits.

1. Define one artifact and 3 to 6 gradeable criteria.
2. Run 2 or 3 candidates only when the design risk justifies the cost.
When available, use one subagent per candidate. Give each the same prompt, rubric, and separate output path.
3. Keep outputs isolated. Never let candidates write the same files.
4. Read every candidate and choose the smallest coherent base.
5. Graft only high-value ideas. Record important rejections.
6. Verify the result against the rubric and inspect the final diff.

If isolation is unavailable, use separate output artifacts or skip the arena. It never replaces tests or review.
