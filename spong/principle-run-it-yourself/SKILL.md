# Run It Yourself

Never hand the human a check you can run.

- Run the command or feature. Read actual output. Inspect the full diff.
- "It compiles," exit code alone, cached output, mtime, and self-report do not prove behavior.
- Script repeatable checks when practical.
- State what you actually ran vs what you only inferred or guessed.
