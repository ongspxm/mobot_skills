### Investigate

Read-only trace and ownership check. Edit nothing.

1. Name question and scope.
2. Read matching AGENTS.md files.
3. Find entry points, types, callers, tests, config, and patterns.
4. Trace one real path from trigger to output or side effect (use read-only scout for big repo).
5. Run cheapest useful check when behavior unclear.
6. Check "git log" or "git blame" (or why skill for rationale/regressions) only for hidden constraints or why.
7. Stop once path clear. Do not catalog unrelated code.

Reply with: overview, step-by-step flow (file:line), gotchas, assumptions, smallest next step (or "no change needed").
