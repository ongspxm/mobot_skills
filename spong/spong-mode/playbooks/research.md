### Research

Focused web and doc research when local code not enough.

1. Split question into 2-4 specific angles (direct answer, official docs/specs, benchmarks/real usage, recent changes).
2. Run targeted searches across those angles.
3. Read full content only for primary or strongest sources; drop stale, duplicate, and SEO pages.
4. Run tighter second pass for gaps; name open gaps instead of guessing.

Reply with: 2-3 sentence summary, numbered findings with citations, Kept vs Dropped sources, open gaps.
