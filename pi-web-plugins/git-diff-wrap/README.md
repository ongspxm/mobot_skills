# Git Diff Wrap

Makes long lines in the PI WEB Git diff viewer wrap to the available panel width instead of requiring horizontal scrolling.

Enable it by linking this plugin into the PI WEB plugin directory:

```bash
mkdir -p ~/.pi-web/plugins
ln -sfn "$PWD/pi-web-plugins/git-diff-wrap" ~/.pi-web/plugins/git-diff-wrap
```

Hard reload PI WEB after enabling or changing the plugin.
